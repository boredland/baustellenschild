# Bauschild

Every permitted construction site in Frankfurt am Main on a cadastral map, at
[bauschild.jonas-strassel.de](https://bauschild.jonas-strassel.de). Click a sign,
read what a passer-by would read at the fence: Bauvorhaben, Bauherr,
Entwurfsverfasser, Bauleiter, Aktenzeichen.

## Where the positions come from

The crawler stores each permit's parcel as Gemarkung / Flur / Flurstück. Those
resolve directly against Frankfurt's official ALKIS parcel service —
`geowebdienste.frankfurt.de/SGK_Flurstuecke`, the same WFS the city's Geoportal
uses — so a marker sits on the surveyed parcel rather than on a geocoded street
address. All 1165 permits resolve; nothing is approximated.

`src/build_site_data.py` (in the repository root, not here) builds two files into
`web/public/data/`:

| file | contents |
| --- | --- |
| `sites.json` | one record per permit, with its marker point |
| `parcels.json` | parcel outlines keyed by Flurstückskennzeichen |

Both are generated by that script and **committed**, because Cloudflare builds
this Worker from git and its builder runs only `npm` — it cannot reach the WFS
or run Python. The output is deterministic (same crawl in, byte-identical files
out), so it does not churn the history.

```sh
python src/build_site_data.py   # from the repository root
cd web && npm install && npm run dev
```

The parcel key is the ALKIS Flurstückskennzeichen,
`06 GMK(4) FLN(3) ZAE(5) NEN(4) __`. A parcel with no Nenner pads that field with
underscores rather than zeros. Where the permit register lags the cadastre on a
parcel split, the build falls back to matching on Gemarkung / Flur / Zähler.

## Deploying

**Cloudflare deploys on every push to `main`** (Workers Builds, root directory
`web`, build `npm run build`, deploy `npx wrangler deploy`). No deploy secrets
live in this repo.

The only thing git cannot produce on Cloudflare's side is the map payload, so
`.github/workflows/map-data.yml` regenerates it whenever `data/baustellen.json`
changes and commits the result — and that commit is what triggers the build.

`npm run deploy` still works for a manual push from a workstation.
